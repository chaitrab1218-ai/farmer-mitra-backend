# Deploying Krushi Mitra Backend to Render.com

This project is fully prepared for 1-click deployment on [Render.com](https://render.com).

---

## Prerequisites
1. A free account on [Render.com](https://render.com).
2. Your repository pushed to GitHub.
3. Your Neon PostgreSQL connection string (`DATABASE_URL`).

---

## Option 1: Automatic Blueprint Deployment (Recommended)

1. Log in to [dashboard.render.com](https://dashboard.render.com).
2. Click **New +** in the top navigation bar and select **Blueprint**.
3. Connect your GitHub repository (`KM`).
4. Render will automatically detect [`render.yaml`](./render.yaml).
5. When prompted for environment variables:
   - **`DATABASE_URL`**: Paste your Neon connection string (e.g. `postgresql://...neon.tech/neondb?sslmode=require`).
   - **`ADMIN_PASSWORD`**: Defaults to `Admin@123` (or choose your own).
   - **`JWT_SECRET`**: Automatically generated by Render.
6. Click **Apply**.
7. Once deployed, Render will provide your public URL (e.g., `https://krushi-mitra-backend.onrender.com`).

---

## Option 2: Manual Web Service Deployment

If you prefer to configure the Web Service manually:

1. In Render Dashboard, click **New +** → **Web Service**.
2. Connect your GitHub repository.
3. Configure the settings:
   - **Name**: `krushi-mitra-backend`
   - **Region**: `Singapore` (closest to India and Neon AP-Southeast)
   - **Root Directory**: `backend`
   - **Environment**: `Node`
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Instance Type**: `Free`
4. Under **Advanced** → **Environment Variables**, add:
   - `DATABASE_URL`: `your_neon_postgres_url`
   - `JWT_SECRET`: `any_strong_random_secret_string`
   - `ADMIN_PASSWORD`: `Admin@123`
   - `NODE_ENV`: `production`
5. Under **Health Check Path**, enter: `/api/health`
6. Click **Create Web Service**.

---

## Connecting the Frontend to Your Render Backend

Once Render gives you your service URL (e.g. `https://krushi-mitra-backend.onrender.com`):

### In Code:
Open [frontend/lib/config.dart](frontend/lib/config.dart) and update `defaultApiUrl`:
```dart
static const String defaultApiUrl = 'https://krushi-mitra-backend.onrender.com';
```

Then build or run your Flutter app:
```powershell
flutter run -d chrome
# or for Android APK:
flutter build apk --release
```
